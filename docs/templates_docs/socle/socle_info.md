
### Règles de réutilisation

| Section                        | Nature     | Adaptation                                      |
| ------------------------------ | ---------- | ----------------------------------------------- |
| 1. Présentation                | Spécifique | Nom et objectif du laboratoire                  |
| 2. Technologies                | Spécifique | Technologies utilisées                          |
| 3. Fonctionnalités             | Spécifique | Fonctionnalités du socle                        |
| 4. Fonctionnalités principales | Spécifique | API, composants, services, etc.                 |
| 5. Qualité du code             | Mixte      | Outils et contrôles utilisés                    |
| 6. CI/CD                       | Commune    | À conserver si l'infrastructure reste identique |
| 7. Branches                    | Commune    | À conserver si la convention reste identique    |


Convention :

- `README.md` : présente le laboratoire et permet de naviguer dans le dépôt.
- `docs/socle.md` : décrit techniquement la base commune.
- `docs/experiences/` : documente chaque expérimentation.
- `tech-lab-index` : centralise l'infrastructure et référence les laboratoires.
