
## Règles de réutilisation

| Section          | Adaptation                                    |
| ---------------- | --------------------------------------------- |
| Présentation     | Nom, domaine et technologie du laboratoire    |
| Socle            | Technologies et fonctionnalités communes      |
| Branches         | À conserver si la convention est identique    |
| Expérimentations | Ajouter uniquement les expériences existantes |
| Annexes          | Adapter les outils et documentations utilisés |
| Index            | Conserver le lien vers `tech-lab-index`       |

Convention que je te recommande :

- `README.md` : présente le laboratoire et permet de naviguer dans le dépôt.
- `docs/socle.md` : décrit techniquement la base commune.
- `docs/experiences/` : documente chaque expérimentation.
- `tech-lab-index` : centralise l'infrastructure et référence les laboratoires.
