# Tech Lab Index

Index central des expérimentations techniques réalisées dans les différents dépôts `lab-*`.

Ce dépôt **ne contient pas le code des expérimentations**. Il permet de retrouver les expériences, les dépôts et les branches qui les composent, ainsi que les éventuels projets indépendants qui en sont issus.

---
## Origine
Le laboratoire est né des besoins d'expérimentation autour de l'écosystème APIKit CEL.
- [Historique des laboratoires](docs/historique.md)
---
## Objectifs

Les labs permettent d'expérimenter et d'apprendre autour de différentes technologies :

- Tester l'implémentation d'une technologie.
- Découvrir et apprendre une nouvelle technologie.
- Vérifier le fonctionnement de plusieurs technologies ensemble.
- Comparer différentes implémentations d'un même besoin.
- Tester ses propres créations dans différents environnements.
- Identifier et extraire du code pouvant devenir un projet réutilisable.
- Conserver une trace des expérimentations réalisées.
